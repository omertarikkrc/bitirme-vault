Wang & Song (2018) §2.1 Denklem 1d — Normal Eksen (ê_n) Kuvvet Dengesi: γ̇

Newton 2. Yasa ê_n (hıza dik, normal eksen) üzerine yansıtılarak γ̇ denklemi elde edilir.
Türetim: m·d(V·ê_t)/dt = F → ê_n bileşeni → mV·γ̇ = F·ê_n
γ açısı -65°
α açısı 5°
mV · γ̇ = (−T sin α) + (−g cos γ / r²)
               ↑ itki ê_n bileşeni     ↑ yerçekimi ê_n bileşeni

Yansıtma adımı: m(V̇·ê_n·ê_t + Vγ̇·ê_n·ê_n) = F·ê_n
                    = 0             = 1  →  mVγ̇ = F·ê_n
α referans ekseni: −ê_t (anti-velocity). α > 0 → thrust −ê_n yönüne kayar → γ̇ < 0.
γ < 0 için cos γ > 0 → −g cos γ < 0 → yerçekimi de −ê_n yönünde → ikisi birlikte γ'yı −90°'ye iter.
